Privacy Policy

Last updated: 15 May 2026

This Privacy Policy describes what information PDF Combiner ("the application", "we", "us") collects, why it is collected, and how it is used. We are committed to collecting the minimum data necessary to operate the application and its optional licensing system.

1. Data we do NOT collect

  • We do not collect, transmit, or store any of your PDF files or their contents.
  • We do not use any analytics, telemetry, or crash-reporting service that sends data to third parties.
  • We do not track your usage of the application, which files you open, or how often you use it.
  • We do not require you to create an account.
  • We do not collect your name, address, or any other personally identifying information unless you initiate a donation.

2. Data collected automatically

2.1 Hardware machine ID

On first launch, PDF Combiner generates a machine ID — a one-way MD5 hash derived from hardware identifiers (CPU ID, BIOS serial, primary MAC address, GPU name). This hash is used solely to activate and validate your license without requiring an account or login. The machine ID:

  • Is sent to our backend (Azure Functions) only when checking for an available license at startup.
  • Is stored in Azure Table Storage associated with your license record, if you have donated.
  • Cannot be used to identify you personally — it is a one-way hardware fingerprint.
  • Is displayed in the About window so you can share it when requesting support.

2.2 Version-check request

At startup, the application sends a single HTTP request to our backend to check for a newer version and to validate your license. This request includes:

  • Your machine ID (see above).
  • The current application version number.

No IP address is stored beyond what is automatically logged by the hosting platform (Azure Functions) in its standard infrastructure logs, which are retained for a short period and used only for diagnosing service issues.

3. Data you provide voluntarily (donation / licensing)

If you donate via PayPal to obtain a full license, PayPal processes your payment and shares the following information with us:

  • Your PayPal email address — used to match the donation to a license record.
  • Your first name — included in PayPal's donation notification email, used only for greeting purposes.

This data is stored in Azure Table Storage and is used exclusively to activate and renew your license. It is never sold, shared with third parties, or used for marketing without your explicit consent.

To exercise your right to access or delete this data, email jankowski.m@gmail.com.

4. Local storage

PDF Combiner stores a small license cache file on your device using Windows Isolated Storage. This file contains:

  • The last known license status (free or full).
  • The license expiry date (if applicable).
  • The last version-check date.
  • The download URL for the latest version.

This data never leaves your device except as described in section 2.2.

5. This website

This website is hosted on GitHub Pages. GitHub may collect standard web server logs (IP address, user agent, referrer) in accordance with GitHub's Privacy Statement. We do not use cookies, analytics scripts, or tracking pixels on this website.

6. Children's privacy

PDF Combiner is not directed at children under 13. We do not knowingly collect personal data from children.

7. Changes to this policy

We may update this policy to reflect changes in the application or applicable law. The "Last updated" date at the top of this page will reflect any revisions.

8. Contact

Questions about this policy? Email us at jankowski.m@gmail.com.
