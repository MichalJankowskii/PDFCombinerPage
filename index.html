Everything you need to combine PDFs

No installs of Acrobat. No uploads to a server. Just your files and your PC.

📂

Drag-and-drop file management

Drop PDFs directly into the list or use the file picker. Reorder files up and down before combining. Select multiple files at once with Ctrl/Shift-click.

📋

Granular page selection

Choose exactly which pages to include per file. Enter a range (1-5), individual pages (1, 3, 7), or a mix. Or click individual page thumbnails directly.

🔄

Per-file page rotation

Rotate a file's pages by 90°, 180°, or 270° before the merge. Applied non-destructively — your original files are never modified.

🔒

Password-protected input PDFs

Open and include password-protected source PDFs. Each file can have its own password; they are stored in memory only for the duration of the session.

🛡

AES-256 output encryption

Optionally protect the merged PDF with a password. Uses AES-256 encryption (iText7). Available to full-license users.

👁

Live page thumbnail preview

Expandable grid showing all pages across all loaded files with applied rotations and selection state. Virtualized rendering keeps the UI fast even for large PDFs.

💻

100% offline — files stay on your PC

PDF Combiner has no cloud component for document processing. Your files are read and written locally. The only network call is an optional version-check on startup.

⚖️

Free for commercial use

The free tier has no commercial-use restrictions. The only difference is a single informational page appended to the merged PDF. Upgrade via a one-time PayPal donation to remove it permanently.
